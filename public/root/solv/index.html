語源 solv（解く）から広がる英単語 7語

語源 solv を共有する英単語を7語まとめました。absolute / absolve / insolvency / resolute / resolution など。意味と語源の説明つき。

  • absolute

    絶対的な，完全な；【名】絶対的なもの

    ラテン語absolutus（解き放たれた，完結した）に由来し、ab-（離れて）とsolvere（解く）の合成語。「他への依存から解き放たれ、完結している」が原義。

  • absolve

    を免除する；を放免する

    ラテン語 absolvere(解き放つ)に由来し、ab-(離れて)+solvere(緩める，解く)から成る。solve と同語源。

  • insolvency

    支払不能，債務超過

    接頭辞 in-（否定）+ solvency（支払能力）から成る。solvencyはラテン語 solvere（解く，支払う）に由来し，「債務を解消する能力」が原義。それを否定することで「債務を解消できない状態」を意味するようになった。

  • resolute

    断固とした

    ラテン語 resolutus（解決した）から。re-（強意）+ solvere（解く，解決する）。

  • resolution

    決意，解決；決議

    ラテン語 resolutio から。resolvere（解決する）が語源

  • solutions

    解決策；解答；溶解；溶液

    ラテン語のsolvere（緩める、解く）に由来し、解決や溶解の意味を持つようになった。

  • solvent

    支払い能力のある；溶剤，溶媒

    ラテン語 solvere(緩める，解く，支払う)の現在分詞 solvens に由来する。「債務を解く」というイメージから支払い能力の意味が生まれた。
