# ブランド画像について

`vercel.json` で、この3種類にだけ `Access-Control-Allow-Origin: *` を付けている。

- `icons/*` … PWA のアイコン
- `og.png` … OGP 画像
- `brand-x-header.png` … X のプロフィールヘッダー（1500x500）

理由: X のプロフィールに画像を設定する際、ブラウザからこれらを読み出す必要が
あった。Vercel の静的配信は既定で CORS を返さないため取得できない。

どれも誰でも見られる公開素材で、秘密は含まない。**`/api/*` には付けないこと**
（認証つきの応答を他サイトに読ませることになる）。
