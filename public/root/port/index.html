語源 port（運ぶ）から広がる英単語 8語

語源 port を共有する英単語を8語まとめました。important / portfolio / purport / purported / rapport など。意味と語源の説明つき。

  • important

    重要な，大切な；主要な

    ラテン語の「importare（〜を運ぶ、〜を意味する）」に由来し、「中に運ばれる」という概念から「価値がある」という意味が派生した。

  • portfolio

    資産構成，作品集

    イタリア語 portafoglio（書類挟み）に由来。portare（運ぶ）+ foglio（紙，葉）から「紙を運ぶもの」の意味が，「保有資産・作品の一覧」に発展した。

  • purport

    と称する；(名詞)趣旨

    古フランス語 purporter（意味する，伝える）に由来し、ラテン語 pro-（前へ）と portare（運ぶ）から「意味を運ぶ」が原義。

  • purported

    うわさされている，主張されている

    ラテン語 purportare（意図する，意味する）から。pro-（前に）+ portare（運ぶ）。

  • rapport

    信頼関係，親密な関係，心の通い合い

    フランス語 rapporter（持ち帰る，対応させる）に由来し，report と同語源の借用語。

  • report

    を報告する，知らせる；を報道する；報告書，記事

    古フランス語の'reporter'（持ち帰る、報告する）に由来し、ラテン語の'reportare'（運ぶ、持ち帰る）から。

  • reports

    報告書，レポート；報道，知らせ；うわさ

    古フランス語の'reporter'（持ち帰る、報告する）から、ラテン語の'reportare'（再び運ぶ、報告する）に由来。're-'（再び）と'portare'（運ぶ）が結合した形。

  • support

    を支える，扶養する；を支持する；を裏付ける；支え，援助

    古フランス語の 'supporter'（下から支える）に由来し、ラテン語の 'sub'（下に）と 'portare'（運ぶ）が結合したもの。
