語源 sist（立つ）から広がる英単語 10語

語源 sist を共有する英単語を10語まとめました。assist / consistent / devastate / estate / state など。意味と語源の説明つき。

  • assist

    を助ける

    ラテン語 assistere「傍に立つ」から。ad（〜へ）+ sistere（立つ）が語源

  • consistent

    一貫した

    ラテン語 consistere「共に立つ」から。con（共に）+ sistere（立つ）が語源

  • devastate

    を壊滅させる，打ちのめす

    ラテン語 devastare（完全に荒廃させる）から。de-（強意）+ vastare（荒廃させる）。

  • estate

    財産，遺産；地所，不動産；〜の状態

    古フランス語の 'estat'（状態、地位）に由来し、ラテン語の 'status'（状態）が起源。土地の所有権や社会的な地位を指すようになった。

  • state

    状態；国家；州

    ラテン語のstare（立つ）に由来し、「立つこと、位置、状態」を意味するstatusを経て、古フランス語のestat、英語のstateに至る。元々は人の地位や状況を指したが、後に政治的な意味も持つようになった。

  • statement

    声明；陳述，言明；明細書

    古フランス語の 'estat' (状態) に由来し、ラテン語の 'status' (立つこと、地位) を経て、英語の 'state' (述べる) から名詞化されました。元々は「述べられたこと」という意味合いです。

  • states

    国家，州；状況，状態；を述べる

    古フランス語の estat（状態、地位）に由来し、ラテン語の status（立つこと、状態）を経由。stateは「立つ」という概念から派生し、固定された状態や政府の組織を意味するようになった。

  • status

    地位，身分；情勢，現状；威信

    ラテン語のstare（立つ）に由来し、「立つこと」「状態」を意味する。

  • statute

    制定法，法令

    ラテン語 statutum（定められたもの）に由来し，statuere（定める，立てる）の過去分詞形から成る。status, statue と語根を共有する。

  • substance

    物質、実体、内容、重要性

    ラテン語のsubstantia（実体、存在）に由来。sub-（下に）とstare（立つ）が組み合わさり、「下に立って支えるもの」、つまり物事の根本にある性質や実体を指すようになった。
