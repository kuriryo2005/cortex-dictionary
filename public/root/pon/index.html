語源 pon（置く）から広がる英単語 11語

語源 pon を共有する英単語を11語まとめました。apposite / component / deposition / impose / juxtapose など。意味と語源の説明つき。

  • apposite

    (状況・目的に)適切な，ぴったり合った

    ラテン語 appositus（ad-〈〜へ〉+ponere〈置く〉の過去分詞、「そばに置かれた」）に由来する。

  • component

    構成要素、成分、部品

    ラテン語の 'com-'（共に）と 'ponere'（置く）に由来し、直訳すると「共に置かれたもの」となる。システムや機械を組み立てるための構成部品を指すようになった。

  • deposition

    証言録取

    ラテン語 deponere（下に置く，証言する）に由来し，de-（下に）+ ponere（置く）から成る。position, compose と語根を共有する。

  • impose

    を課す

    ラテン語 imponere「上に置く」から。in（上に）+ ponere（置く）が語源

  • juxtapose

    を並置する

    フランス語 juxtaposer から。ラテン語 juxta（隣に）+ ponere（置く）。

  • opponent

    (競技・議論などの)相手，敵，対戦相手

    ラテン語opponere「反対に置く」に由来。ob-(~に対して)+ponere(置く)で「自分の前に立ちはだかる者」が原義。

  • position

    位置，場所；立場，状況；姿勢；(仕事の)職，ポスト

    ラテン語の ponere（置く）の過去分詞 positus に由来し、「置かれた状態・場所」を意味する。

  • post

    郵便物；郵便，ポスト；(職)に就かせる；を掲示する

    ラテン語の"positus"（置かれた）に由来し、伝令が情報を置く場所を指すようになった。

  • posted

    を掲示する，張る；を配置する；インターネットに投稿する

    ラテン語「ponere」（置く）に由来し、中世フランス語を経て「poste」（駅、位置）となり、英語の「post」になった。

  • proponent

    支持者，提唱者

    ラテン語 proponere「前に置く，提案する」から

  • repository

    貯蔵庫，宝庫

    ラテン語 repositorium「置き場」から。re（後ろに）+ ponere（置く）が語源
