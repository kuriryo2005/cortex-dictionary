語源 ven（来る）から広がる英単語 9語

語源 ven を共有する英単語を9語まとめました。advent / circumvent / convene / conventional / event など。意味と語源の説明つき。

  • advent

    出現；到来

    ラテン語 adventus(到着)に由来し、ad-(〜へ)+venire(来る)から成る。event, convention と同語源。

  • circumvent

    を回避する，出し抜く

    ラテン語 circumvenire（周りを回って来る）から。circum-（周りに）+ venire（来る）。

  • convene

    (会議など)を招集する

    ラテン語 convenire（共に来る）から。com-（共に）+ venire（来る）。

  • conventional

    従来の，型にはまった

    ラテン語 conventio「集合」から。con（共に）+ venire（来る）が語源

  • event

    出来事，行事；事件；結果

    ラテン語のex-（外へ）とvenire（来る）に由来し、「外に出てくるもの」の意。

  • events

    出来事；行事；事柄

    ラテン語のex-（外へ）とvenire（来る）に由来し、「外に出てくるもの、結果」という意味から「出来事」を指すようになった。

  • intervene

    介入する

    ラテン語 intervenire「間に来る」から。inter（間に）+ venire（来る）が語源

  • revenue

    収益，歳入

    古フランス語 revenue（戻ってくるもの）に由来。ラテン語 revenire（戻る，帰る）から，「（投資などから）返ってくるもの」という意味が「収入」に発展した。

  • venture

    冒険的事業；思い切って（危険を冒して）〜する

    adventure が短縮された語で，ラテン語 advenire（到来する）に由来する。
