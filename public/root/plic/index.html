語源 plic（折る・畳む）から広がる英単語 9語

語源 plic を共有する英単語を9語まとめました。application / applications / complicity / duplicity / explicit など。意味と語源の説明つき。

  • application

    応用，適用；出願，申請；塗布，塗ること

    ラテン語のapplicare（〜に折り畳む、取り付ける）に由来し、英語では「適用する」「注意を向ける」といった意味を経て現在の「応用」「申請」の意味に至る。

  • applications

    応用；適用；申し込み

    ラテン語のapplicare（〜に折り畳む、取り付ける）に由来。apply（適用する、申し込む）の名詞形。

  • complicity

    共犯，共謀，加担

    ラテン語 complicare（折り畳む，絡ませる）に由来し、com-（共に）+ plicare（折る）から「共に絡み合っていること」が原義。complex, employ とも同語源。

  • duplicity

    二枚舌；欺瞞

    ラテン語 duplex(二重の，duo二 + plicare折る)に由来する。

  • explicit

    明示的な，明確な

    ラテン語explicare「開いて広げる，説明する」に由来。ex-(外へ)+plicare(折りたたむ)が語源で、「折りたたまれたものを広げて明らかにする」が原義。

  • implicit

    暗黙の，暗示された

    ラテン語 implicare（絡み合わせる）から。in-（中に）+ plicare（折り畳む）。

  • perplex

    を当惑させる，を混乱させる

    ラテン語 perplexus（絡み合った，複雑な）に由来し、per-（完全に）と plectere（編む，織る）から成る。

  • reply

    に返事をする；と答える；返事，応答

    古フランス語のreplier（折り返す、答える）に由来し、ラテン語のreplicare（折り返す、繰り返す、答える）から。re-（再び）+ plicare（折る）。

  • supplicate

    嘆願する；懇願する

    ラテン語 supplicare（ひざまずく，嘆願する）に由来し、sub-（下に）+ plicare（折る）が語源とされる。
