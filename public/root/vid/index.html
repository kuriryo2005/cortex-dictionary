語源 vid（見る）から広がる英単語 13語

語源 vid を共有する英単語を13語まとめました。devise / dividend / evident / improvisation / provide など。意味と語源の説明つき。

  • devise

    を考案する

    古フランス語 deviser（分割する，工夫する）から。ラテン語 dividere（分ける）に由来する。

  • dividend

    配当金

    ラテン語 dividendum（分けられるべきもの）に由来。dividere（分ける）から派生し，利益を株主に「分配する」という意味に発展した。

  • evident

    明白な

    ラテン語 evidens「はっきり見える」から。e（外に）+ videre（見る）が語源

  • improvisation

    即興，即興演奏

    ラテン語 improvisus（予見されていない）に由来し，in-（否定）+ providere（予見する）から成る。「あらかじめ見通されていない」ことから「その場で作り出す」の意味へと発展した。

  • provide

    (物)を供給する，提供する；(人)に供給する，与える；(法・規定などが)定める

    ラテン語pro-（前に）+ videre（見る）から来ており、「前もって準備する、用意する」が原義。

  • provided

    〜という条件で；〜ならば；〜が与えられれば

    ラテン語の 'providere'（前もって見る、準備する）に由来し、'pro-'（前へ）と 'videre'（見る）から成る。

  • providence

    摂理；先見の明

    ラテン語 providentia（先見，配慮）に由来し、pro-（前もって）と videre（見る）が結合した「先を見通すこと」が原義。

  • provides

    (物)を供給する，提供する；(機会など)を与える；を規定する

    ラテン語の"providere"（"pro-"「前に」+ "videre"「見る」）に由来し、「前もって見る、準備する」という意味を持つ。

  • provisional

    暫定的な，仮の

    ラテン語 providere（あらかじめ備える）に由来し、pro-（前もって）+ videre（見る）から成る。「先を見越して備える」が原義。

  • video

    ビデオ；動画；録画する

    ラテン語の "videre" (見る) に由来。

  • videos

    動画，映像；ビデオ（録画）；ビデオデッキ

    ラテン語の「videre」（見る）に由来する「video」（私は見る）から。1930年代にテレビジョン技術とともに使われ始めた。

  • visage

    顔つき，容貌

    古フランス語 visage（顔つき）を経て，ラテン語 visus（見えるもの，videre「見る」に由来）にさかのぼる。

  • visit

    を訪問する，見舞う；に一時滞在する，泊まる

    古フランス語のvisiter（訪れる）に由来し、ラテン語のvisitare（訪れる、見舞う）から。vision（見る）と同語源。
