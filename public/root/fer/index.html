語源 fer（運ぶ）から広がる英単語 16語

語源 fer を共有する英単語を16語まとめました。aquifer / confer / conference / defer / deference など。意味と語源の説明つき。

  • aquifer

    帯水層

    ラテン語aqua(水)+ferre(運ぶ)から成り，「水を運ぶもの」が原義。

  • confer

    協議する，を授与する

    ラテン語 conferre（持ち寄る）から。com-（共に）+ ferre（運ぶ）。

  • conference

    会議，協議；協議会，学会；会談

    ラテン語のconferre（一緒に運ぶ、比較する）に由来し、中英語で「話し合う」という意味が加わった。

  • defer

    を延期する，従う

    ラテン語 differre（運び去る，延期する）から。dis-（離れて）+ ferre（運ぶ）。

  • deference

    服従；敬意

    ラテン語 deferre(de-下へ + ferre運ぶ、ゆだねる)に由来する。

  • differ

    異なる，違う；(...と)意見を異にする

    ラテン語のdifferre「離れて運ぶ、異なっている」から。dis-（離れて）+ ferre（運ぶ）

  • different

    異なる，違った；様々な，色々な

    古フランス語の 'différent' (異なる) に由来し、ラテン語の 'differre' (分かれる、異なる) から。

  • differentiate

    を区別する

    ラテン語 differentiare（異なるようにする）から。differre（異なる）に由来する。

  • infer

    を推測する

    ラテン語 inferre（持ち込む，結論づける）から。in-（中に）+ ferre（運ぶ）。

  • offer

    を申し出る；(人)に(物)を提供する；申し出，提供

    古英語の「ofrian (捧げる、提供する)」に由来し、ラテン語の「offerre (差し出す)」が語源。

  • offers

    を申し出る，提供する；申し出，提案

    古英語の「ofrian」(差し出す、提供する)に由来し、ラテン語の「offerre」(差し出す)が語源。

  • proliferate

    急増する，増殖する

    ラテン語 proles（子孫）+ ferre（運ぶ，生む）から。生物学の「増殖する」から一般語へ転用された。

  • referee

    審判員，レフェリー；(試合)を審判する

    ラテン語referre「差し戻す，報告する」に由来。判定を「(上位の規則に)差し戻して確認する人」が原義で、そこから「審判」の意味に発展した。

  • reference

    参照，参考；言及；照会

    ラテン語referre（持ち帰る、参照する）に由来し、re-（再び）+ ferre（運ぶ）で構成される。

  • referendum

    国民投票，住民投票

    ラテン語 referre（re-＝戻す＋ferre＝運ぶ，持って行く）の動名詞的用法に由来し，「（決定を人々のもとへ）差し戻すもの」という意味から，直接民意を問う投票を指すようになった。

  • vociferous

    騒々しい，声高な

    ラテン語 vox（声）と ferre（運ぶ）の合成語 vociferari（叫ぶ）に由来する。
