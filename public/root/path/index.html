語源 path（感情・苦しみ）から広がる英単語 6語

語源 path を共有する英単語を6語まとめました。antipathy / apathetic / apathy / empathy / pathogen など。意味と語源の説明つき。

  • antipathy

    反感，嫌悪

    ギリシャ語 anti-(反対の)+pathos(感情)に由来し、「反対の感情」が原義。sympathy(共感)の対義的構造を持つ語。

  • apathetic

    無関心な，無感動な

    ギリシャ語apatheia(a-「~がない」+pathos「感情，苦しみ」)に由来。ストア派哲学では感情に動じない理想的境地を意味したが，現代英語では否定的に「感情・関心の欠如」を表すようになった。

  • apathy

    無関心

    ギリシャ語 apatheia（無感動）から。a-（否定）+ pathos（感情）。

  • empathy

    共感、感情移入

    ギリシャ語の「en-」（中に）と「pathos」（感情、苦痛）を組み合わせた「empathia」に由来します。相手の感情の「中」に入り込むという語源的背景があります。

  • pathogen

    病原体

    ギリシア語 pathos（苦しみ，病気）+ -gen（生み出すもの，genēs「生まれた」に由来）から成る合成語で，「病気を生み出すもの」が文字通りの意味。19世紀に細菌学の発展とともに定着した。

  • pathos

    哀愁，悲哀の情

    ギリシャ語 pathos（苦しみ，感情）に由来し、pathetic（哀れな）や empathy（共感）と語根を共有する。
